# 松菱民主党 公式サイト（ウェブサイト制作版）

松菱民主党のこれまでの方針・保存済みビジュアルを踏まえて作成した、レスポンシブなワンページ公式サイトです。

## 開き方

- `index.html` をブラウザで開くと閲覧できます。
- `assets/` フォルダーを含め、ファイルの配置を変えずに使用してください。
- ナビゲーションはページ内セクションへ移動します。政策カードとニュース本文は押すと詳細が開き、ニュースは「国内政治」「国際情勢」で絞り込めます。スマートフォンではメニューも開閉します。

## 主な内容

- 党の理念と基本姿勢
- 6つの重点政策と詳細説明
- 政策を検討する際の基本姿勢
- 国内政治・国際情勢のニュースと松菱民主党プロジェクトの見解
- 報道元へのリンク、分野別フィルター、記事本文の開閉表示
- 第3代代表 OHTANISHOHEY17 のメッセージ
- 歴代代表
- Scratch公式スタジオへのリンク

## 公開する場合

このフォルダー全体をGitHubリポジトリにアップロードし、リポジトリの Settings → Pages から公開できます。公開前に、写真素材・政策文章・代表者情報・外部リンクが最新の意向と合っているか確認してください。

## 素材について

`assets/representative-visual.webp` は、以前の松菱民主党選挙ポスター素材から切り出した代表イメージです。実在人物の写真として新規に撮影・検証したものではありません。`community-scene.webp` と `public-scene.webp` は、保存済みの公式サイトビジュアルから切り出した画像です。

## 表記について

ページ下部に、Scratch上の架空の政党プロジェクトであることを示す説明を入れています。実在する国政政党・公的機関と誤認されないよう、公開時もこの説明を残してください。

## ニュース・党の見解について

ニュース欄には2026年10月26日時点の公開報道を参考にした記事例を掲載しています。各記事で「報道内容」と「松菱民主党の見解」を分け、報道元へのリンクを付けています。公開報道の内容や国際情勢は変化するため、実際に継続運用する際は日付・事実関係・出典URLを確認して記事を更新してください。党の見解部分は、松菱民主党プロジェクトの理念に沿って作成した提言文です。
